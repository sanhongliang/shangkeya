## 一、服务器现状（与本项目共存的服务）

| 服务 | 路径 | 端口 | 说明 |
|---|---|---|---|

## 二、部署结构

```
公网 80 ── Caddy
           ├── /            → /var/www/shangkeya-mobile（手机端课表网页）
           └── /api/*       → 127.0.0.1:3000（Node.js 后端，仅本机回环）

后端：/opt/shangkeya/backend
  - systemd 服务：shangkeya（自动重启）
  - 监听：127.0.0.1:3000（不对外暴露）
  - 环境变量：/opt/shangkeya/backend/.env（PG 连接 + JWT_SECRET + HOST=127.0.0.1 + PORT=3000）

数据库：PostgreSQL 16（Ubuntu 自带）
  - 库：shangkeya ｜ 用户：shangkeya（密码见 C:\shangkeya-backend-test\scripts\pg-pwd.txt）
  - 表：accounts/students/courses/schedule/recharges/scores/announcements/settings/week_schedule
  - 管理账号：admin / admin123  ⚠️ 生产环境请尽快修改密码
```

## 四、桌面端连接服务器

桌面端 `src/api/client.ts` 默认 `http://localhost:3000`，生产环境打包时需改为服务器地址。两种方式：
1. 打包产物 `index.html` 注入 `<script>window.__SHANGKEYA_API__='http://82.156.240.204/api'</script>`
2. 或改 `client.ts` 默认值为 `http://82.156.240.204/api`

## 五、运维命令（服务器上）

```bash
sudo systemctl status shangkeya      # 后端状态
sudo systemctl restart shangkeya     # 重启后端
sudo journalctl -u shangkeya -n 50   # 后端日志
sudo systemctl reload caddy          # 重载 Web 入口
```
